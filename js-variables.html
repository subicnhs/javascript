Slide 2

Learning Objectives

By the end of this lesson, learners can:

  • Declare and use variables and common JavaScript data types.
  • Create and call functions inside an HTML webpage.
  • Solve problems using JavaScript operators.
  • Respond to user actions using event handlers and event listeners.

Review and Setup

Slide 3

Review: HTML + CSS + JavaScript

  • HTML = structure and content
  • CSS = appearance and layout
  • JavaScript = behavior and interactivity

Example: HTML creates a button; JavaScript responds when the button is clicked.

Slide 4

Where JavaScript Goes in HTML

  • Write JavaScript inside a <script> element, often before </body>.
  • The browser runs the script when it loads or when an event occurs.
<button id="hello">Say Hello</button>
<script>
  document.getElementById("hello").onclick = function() {
    alert("Hello, class!");
  };
</script>

Variables and Data Types

Slide 5

What Is a Variable?

  • A variable is a named container for a value.
  • Use let for values that may change.
  • Use const for values that should not be reassigned.
  • Avoid var in new beginner projects.
let studentName = "Ana";
let score = 85;
const passingScore = 75;
score = 90;  // allowed
// passingScore = 80; // not allowed
Slide 6

Variable Naming Rules

  • Names can include letters, digits, _ and $.
  • Names cannot begin with a digit.
  • Names are case-sensitive: score ≠ Score.
  • Do not use reserved keywords.
  • Use descriptive camelCase names.
let totalScore = 95;  // good
let studentAge = 17;  // good
// let 1score = 95;  // invalid
Slide 7

JavaScript Data Types

  • String: text — "Hello"
  • Number: integers and decimals — 12, 3.5
  • Boolean: true or false
  • Undefined: declared but not assigned
  • Null: intentionally empty

Objects and arrays store related data.

let name = "Mia";
let age = 17;
let enrolled = true;
let middleName = null;
let subjects = ["HTML", "JavaScript"];
Slide 8

Check a Data Type

Use typeof to inspect the type of a value.

Remember: values entered into HTML input fields are strings by default.

let count = 10;
console.log(typeof count); // "number"
let input = "10";
console.log(typeof input); // "string"
console.log(Number(input) + 5); // 15
Slide 9

Getting Values from HTML

  • Select an HTML element by its id.
  • Read input with .value.
  • Use Number(...) when doing arithmetic.
<input id="age" type="number">
<button onclick="showAge()">Check</button>
<p id="result"></p>
<script>
function showAge() {
  let age = Number(document.getElementById("age").value);
  document.getElementById("result").textContent = age;
}
</script>

Functions

Slide 10

What Is a Function?

  • A function groups reusable instructions.
  • It runs when you call its name.
  • Parameters receive values; return sends back a result.
function greet(name) {
  return "Hello, " + name + "!";
}
let message = greet("Ana");
console.log(message); // Hello, Ana!
Slide 11

Functions in a Webpage

  • HTML displays the content.
  • JavaScript computes and updates the page.
  • textContent safely changes visible text.
<p id="output"></p>
<script>
function add(a, b) {
  return a + b;
}
document.getElementById("output").textContent =
  "Sum: " + add(5, 7);
</script>

Operators

Slide 12

Arithmetic Operators

  • + Addition
  • − Subtraction
  • * Multiplication
  • / Division
  • % Remainder (modulo)
  • ** Exponent

Example: 17 % 5 = 2

let a = 17, b = 5;
console.log(a + b);  // 22
console.log(a / b);  // 3.4
console.log(a % b);  // 2
console.log(2 ** 3); // 8
Slide 13

Assignment Operators

  • = Assign a value
  • += Add then assign
  • -= Subtract then assign
  • *= Multiply then assign
  • /= Divide then assign
let points = 10;
points += 5;  // 15
points -= 3;  // 12
points *= 2;  // 24
Slide 14

Comparison Operators

  • === Strict equality (value and type)
  • !== Strict inequality
  • > Greater than
  • < Less than
  • >= Greater or equal
  • <= Less or equal

Comparisons return true or false.

console.log(10 > 7);       // true
console.log(10 === "10"); // false
console.log(75 >= 75);     // true
Slide 15

Logical Operators

  • && AND: both conditions must be true
  • || OR: at least one condition must be true
  • ! NOT: reverses a Boolean

Use them when checking multiple requirements.

let score = 85;
let submitted = true;
let passed = score >= 75 && submitted;
console.log(passed); // true
Slide 16

Problem Solving: Pass or Fail

Problem: A learner passes if the score is at least 75.

Algorithm: read score → compare with 75 → show result.

let score = 82;
let result = score >= 75 ? "Passed" : "Failed";
console.log(result); // Passed

Events

Slide 17

What Is an Event?

  • An event is an action detected by the browser.
  • Examples: click, input, change, submit, mouseover.
  • JavaScript can respond when an event happens.

An event handler is the code that runs in response.

Slide 18

Event Handler: onclick

  • An inline event handler is easy to demonstrate.
  • For larger projects, addEventListener is generally preferred because it keeps HTML and JavaScript separate.
<button onclick="sayHello()">Click Me</button>
<p id="message"></p>
<script>
function sayHello() {
  document.getElementById("message").textContent =
    "Welcome to JavaScript!";
}
</script>
Slide 19

Event Listener: addEventListener

  • addEventListener connects an event to a function.
  • It can support multiple listeners on the same element.
  • Use it after the relevant HTML element exists.
<button id="btn">Click Me</button>
<p id="message"></p>
<script>
document.getElementById("btn").addEventListener(
  "click", function() {
    document.getElementById("message").textContent = "Clicked!";
  }
);
</script>
Slide 20

Live Input Example

  • The input event runs as the user types.
  • This makes webpages respond immediately.
<input id="name" placeholder="Enter your name">
<p id="greeting"></p>
<script>
document.getElementById("name").addEventListener(
  "input", function(event) {
    document.getElementById("greeting").textContent =
      "Hello, " + event.target.value;
  }
);
</script>

Practice

Slide 21

Guided Practice: Two-Number Calculator

Task: Enter two numbers and click Add.

Concepts: variables, Number(), function, + operator, click listener.

<input id="num1" type="number">
<input id="num2" type="number">
<button id="addBtn">Add</button>
<p id="answer"></p>
<script>
function add(a, b) { return a + b; }
document.getElementById("addBtn").addEventListener("click", () => {
  const a = Number(document.getElementById("num1").value);
  const b = Number(document.getElementById("num2").value);
  document.getElementById("answer").textContent = add(a, b);
});
</script>
