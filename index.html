Basics

Slide 3

HTML + CSS + JavaScript

  • HTML = structure and content
  • CSS = appearance and layout
  • JavaScript = behavior and interactivity

Example: clicking a button changes the text on a page.

Slide 4

What is JavaScript?

  • A programming language used to make web pages interactive.
  • Runs in a web browser.
  • Can respond to clicks, validate input, and change page content.

JavaScript is different from Java.

Adding JavaScript to a Page

Slide 5

Three Ways to Add JavaScript

  • Inline: onclick="alert('Hello!')"
  • Internal: <script> ... </script> inside an HTML file
  • External: <script src="script.js"></script>

External scripts help keep code organized.

Slide 6

Your First JavaScript Webpage

<!DOCTYPE html>
<html>
<body>
  <h1 id="title">Hello!</h1>
  <button onclick="changeText()">Click Me</button>
  <script>
    function changeText() {
      document.getElementById("title").textContent = "Welcome!";
    }
  </script>
</body>
</html>
Slide 7

Understanding the Example

  • <h1 id="title"> creates an identifiable heading.
  • <button> creates a clickable control.
  • onclick calls a JavaScript function.
  • getElementById finds the heading.
  • textContent changes the displayed words.

Statements and Control

Slide 8

JavaScript Statements

A statement is an instruction for the computer.

let name = "Ana";  // declare a variable
let score = 85;     // store a number
console.log(name);  // display in developer console

Statements often end with semicolons.

Slide 9

Sequence, Selection, Repetition

  • Sequence: instructions run in order.
  • Selection: if / else chooses an action.
  • Repetition: for / while repeats actions.

These are fundamental control structures.

Slide 10

Example: Conditional Statement

let score = 85;
if (score >= 75) {
  console.log("Passed");
} else {
  console.log("Try again");
}

Output: Passed

Algorithms, Pseudocode, and Flowcharts

Slide 11

What is an Algorithm?

A clear, finite sequence of steps to solve a problem.

Example: Check whether a student passed.

  1. Start
  2. Read score
  3. If score >= 75, show Passed; otherwise show Failed
  4. End
Slide 12

Pseudocode Example

START
INPUT score
IF score >= 75 THEN
    DISPLAY "Passed"
ELSE
    DISPLAY "Failed"
END IF
END

Pseudocode describes logic without strict programming syntax.

Slide 13

Flowchart Symbols

  • Oval = Start / End
  • Parallelogram = Input / Output
  • Rectangle = Process
  • Diamond = Decision
  • Arrows = Direction of flow
Slide 14

Flowchart: Passing Score

START
INPUT score
Is score >= 75?
YES
DISPLAY Passed
END
NO
DISPLAY Failed
END

Practice

Slide 15

Convert the Logic to HTML + JavaScript

<input id="score" type="number" placeholder="Score">
<button onclick="checkScore()">Check</button>
<p id="result"></p>
<script>
function checkScore() {
  const score = Number(document.getElementById("score").value);
  document.getElementById("result").textContent =
    score >= 75 ? "Passed" : "Failed";
}
</script>
